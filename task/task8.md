Modeling using autowwtp-asm.Data are located at input/data8.xlsx. Build an ASM model to simulate an anoxic tank, including COD degradation and simplified nitrogen removal. The boundaries to consider are internal recycle (internal recycle exchange rate coefficient is 0.5 /h, recycle liquor nitrate nitrogen concentration is 25 mg/L, and recycle liquor dissolved oxygen concentration is 0.5 mg/L) + sludge return (sludge return rate coefficient is 0.5 /h, and return sludge concentration is 2 times the steady-state concentration) + hydraulic connection (hydraulic exchange rate coefficient is 0.2 /h, and influent concentration is taken from the first row of the data8 data table). Calibrate nitrate nitrogen, readily biodegradable COD, and heterotrophic biomass. Please keep intermediate files and analyze the modeling process and results.
