Modeling using autowwtp-asm.Data are located at input/data4.xlsx. Build an ASM model to simulate an anaerobic tank, including COD degradation, simplified nitrogen removal, and enhanced biological phosphorus removal. The boundaries to consider are sludge return (sludge return rate coefficient is 0.5 /h, and return sludge concentration is 2 times the steady-state concentration) + hydraulic connection (hydraulic exchange rate coefficient is 0.2 /h, and influent concentration is taken from the first row of the data4 data table) + external carbon dosing (readily biodegradable soluble COD dosing rate is 10 mg COD/L/h, acting on the readily biodegradable soluble COD component). Calibrate readily biodegradable COD, orthophosphate, and poly-beta-hydroxyalkanoate. Please keep intermediate files and analyze the modeling process and results.
