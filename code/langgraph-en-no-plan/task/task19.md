Modeling using autowwtp-asm.Data are located at input/data19.xlsx. Build an ASM model to simulate a pre-anoxic tank, including COD degradation and simplified nitrogen removal. The boundaries to consider are sludge return (sludge return rate coefficient is 0.5 /h, and return sludge concentration is 2 times the steady-state concentration) + hydraulic connection (hydraulic exchange rate coefficient is 0.2 /h, and influent concentration is taken from the first row of the data19 data table). Calibrate nitrate nitrogen, readily biodegradable COD, and heterotrophic biomass. Please keep intermediate files and analyze the modeling process and results.
