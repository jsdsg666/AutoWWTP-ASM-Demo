# Task Writing

Write tasks with these elements:

- data path
- process type or tank role
- target pollutants or calibration variables
- boundary conditions, if any
- calibration mode
- any preference on output detail

## Good task shape

- short
- explicit
- contains the actual `input/*.xlsx` path
- names the process and targets directly

## Avoid

- vague process descriptions
- missing data path
- invented boundary terms
- mixing planning intent with implementation detail
