# Artifact Schema

## Key outputs

- `output/task-*/asm_report.md`: narrative report
- `output/task-*/asm_report.pdf`: rendered report
- `output/task-*/final_result.json`: summary status and paths
- `output/task-*/execution_trace.json`: execution metadata
- `output/task-*/process_checks.json`: integrity checks

## Midoutput files

- `midoutput/WWTPProcessContext.md`
- `midoutput/asm_plan.md`
- `midoutput/asm_config_before.json`
- `midoutput/asm_config_after.json`
- `midoutput/asm_config.json`
- `midoutput/param_ori.json`
- `midoutput/param_ref.json`
- `midoutput/param_opt.json`
- `midoutput/sensitivity.json`
- `midoutput/calibration.json`
- `midoutput/model.py`

## Figure files

- `figs/fig1_*` to `figs/fig8_*`

Use the JSON files for machine checks and the Markdown/PDF for human review.
